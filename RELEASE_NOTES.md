# Release notes

## 1.0.0+1

First release of Tavryn, a local-only intermittent fasting timer.

- Live progress ring with remaining time and goal clock
- Preset protocols (`12h/12h` through 72h + Flexi) plus custom schedules
- Editable history (start/end, protocol, optional note, swipe to delete)
- Pulsing **Live** marker on the active fast
- Timeline in a bottom sheet
- Trends: streaks, totals, hit-goal %, days fasted, week/month/year, weekly hours, heatmap
- Local notifications (start, goal, eating window, optional stages)
- AES-CBC encrypted on-device storage and optional PIN lock
- Import / Export JSON; PIN-protect is optional on export
